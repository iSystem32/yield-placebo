# SPEI — Sombra Digital

SPEI es un SIPS (Systemically Important Payment System). No es P2P. Es centralizado en Banxico y es sistémico.

## Etiqueta de datos por pago de $50

Un pago "sin fricción" requiere en conjunto:

- **Identidad (SENSIBLE):** Nombre, CURP, RFC, KYC
- **Patrimonial:** CLABE, saldo, monto
- **Dispositivo (SENSIBLE):** Device ID, IP, biometría, token
- **Ubicación (SENSIBLE):** GPS, geocerca, IP location
- **Conductual:** Frecuencia, grafo de contrapartes, ticket promedio
- **Regulatorio:** Logs Banxico/CNBV/SAT por 5+ años, capacidad de reversión

La suma de datos no sensibles crea un dato sensible por inferencia. El efectivo no deja sombra. Lo digital sí.

La fricción cero es el placebo.
